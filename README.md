# Gumball QR Studio

I want to create a website that allows other links, URLs, files, folders to create a QR code and make it interesting like a gumball dispenser. And, uh, it should not be like the same typical QR code generators.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://geturumball.lovable.app
